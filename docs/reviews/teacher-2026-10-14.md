## Limits of this run

- Small control samples: 4 planted-fault passages and 4 recall pairs are smoke checks for drift of the reviewer, not estimates.
- One model family: the reviewer is an Opus model, the family that also writes the engine's rules, so blind spots can be shared (docs/research/teacher-review.md section 8).
- PIG bars are estimated from the performance timing (docs/research/teacher-review.md 2.2); hard-error passages are counted here and never quoted.
- User-edited passages (verification spec 3.12 item d) are out of scope until M5 stores edits in the app.
- The brief still tells reviewers that some fingerings are by expert pianists, although none are this run; the sentence is kept verbatim so the numbers stay comparable with the pilot (docs/research/teacher-review.md 6.3).
- Never a gate: no floor reads these numbers, pnpm verify never runs this job, and nothing is tuned on them (verification spec 3.12).
- Planted faults found by position: 100% this run against 99% in the pilot; a drop is a finding about the reviewer, not about the engine.
