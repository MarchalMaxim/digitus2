# Shared library of readers' scores: build plan

Issue: [#132](https://github.com/MarchalMaxim/digitus2/issues/132). Options and judgement: `docs/research/shared-library-options.md`. Mock-ups: https://claude.ai/artifact/MwN2J2jY2RDQGVUDk2jCyb.

The owner chose the pre-moderated store, in a Google Cloud project of its own with no billing account, and moderates in the Firebase console alone (no command, no index document).

## Store contract

Firestore REST, no SDK: `https://firestore.googleapis.com/v1/projects/digitus2-library/databases/(default)/documents`. The base URL lives in `apps/web/src/library/shared/store.ts`; `VITE_LIBRARY_STORE` overrides it (e2e, emulator). No auth header, no API key.

Collection `shared`, document id = 32 lowercase hex from `crypto.getRandomValues` (128 bits). Fields (Firestore typed values):

| Field      | Type      | Rule                                                                                                                                                                                                             |
| ---------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`    | string    | 1–120 chars                                                                                                                                                                                                      |
| `composer` | string    | 0–120 chars                                                                                                                                                                                                      |
| `score`    | string    | 1–100,000 chars: the MusicXML text, `CompressionStream('deflate-raw')`, base64                                                                                                                                   |
| `kind`     | string    | `scan` or `file`                                                                                                                                                                                                 |
| `app`      | string    | 0–40 chars, the app version                                                                                                                                                                                      |
| `status`   | string    | `waiting` on create; the owner sets `shared` in the console                                                                                                                                                      |
| `created`  | timestamp | `request.time` (REST: `currentDocument` is not used; send a transform write via `:commit` with `setToServerValue: REQUEST_TIME`, or create then reject on mismatch; the rules require `created == request.time`) |
| `link`     | string    | `https://marchalmaxim.github.io/digitus2/#/shared/<id>`, so the owner can open it from the console                                                                                                               |

Create: `POST …/documents:commit` with one `update` write (`currentDocument.exists=false`) and an `updateTransforms` entry `created` = `REQUEST_TIME`. Get: `GET …/documents/shared/<id>`. Delete: `DELETE …/documents/shared/<id>`. Shelf: `POST …/documents:runQuery` with `where status == "shared"`, `orderBy created DESCENDING`, `limit`, `select` title, composer, created (cursor `startAt` for "More").

Collection `reports`, id 32 hex. Fields: `score` (the shared id), `reason` (`copyright`, `abuse`, `broken`), `note` (0–1,000), `reply` (0–200; required non-empty for copyright), `created` (request time). Create only.

The record in My scores (`records.ts`) gains an optional `shared?: { id: string }`; the database version stays 1 (an optional field).

## Tests

- **Rules** (`library-store/rules.test.mjs`: the app's own REST calls against the Firestore emulator, which runs in Docker): a good create passes; each bad shape is refused (extra field, missing field, long title, long score, wrong kind, status other than `waiting`, client-chosen `created`, bad id, wrong link); get passes for any id; list passes only constrained to `status == "shared"`; delete passes only while `waiting`; update is refused; reports: good create passes, copyright without reply refused, read refused.
- **Unit** (vitest): the payload holds no file name and no record id; deflate round-trip; the 100,000-character cap refuses a larger score with a notice; title prefill order; eligibility (MIDI refused, a file failing the strict import refused); REST request shapes; route `#/shared/<id>` parses only 32-hex ids.
- **e2e** (Playwright, store faked): Share appears only on eligible rows; the sheet's tick rule; one red while the sheet is open; Share sends exactly one commit and nothing before; the row turns to Waiting and Withdraw sends a delete; the shelf renders from a faked query and opens a shared score at `#/shared/<id>`, which is not added to My scores; Report sends one create; the failure path shows the GitHub link; desktop and phone widths.
- `pnpm verify` before the PR.
